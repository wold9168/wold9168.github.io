## 技术栈

我编程语言方面的技术栈包括：Bash、C、C++、Golang、Java、JavaScript、Python、Scala。其中 C 和 Golang 的掌握程度稍好些，其他的编程语言大部分时候只能算个添头。

工具语言方面，我会使用 Typst、LaTeX 和 Markdown；JSON、Yaml、SQL 我也基本都能熟练使用。

我专注于容器化技术、数据库、数据科学、大数据技术、网络应用后端开发这些技能的学习。未来希望在边缘计算、大规模并行计算、高性能计算、容器化技术、操作系统内核等领域有所建树。

我最喜欢的技术栈是 Linux。我幼年时曾想在网络安全上有所建树。

我暂时对前端一无所知、对软件打包所知甚少。

我正在学习 Rust。我不是锈小鬼，不过的确欣赏 Rust 语言所凝聚的工程经验。

我希望学习 Nix、Haskell 和编译器，但是我对编译器的方面没什么天赋。

系统方面，我曾是 Arch Linux 用户，后转至 Debian，现主力使用 Fedora。虽偏好 Fedora 的集成特性，但对其他发行版亦持开放态度。我已经不再使用 Windows。我对红帽系的技术没有抵触情绪。我希望学习使用 NixOS。我觉得使用函数式语言「决定性」地配置一台设备是优雅的。

我使用 [Zed](https://zed.dev) 和 VSCodium 作为我的主要编辑器。我不介意在工程项目中使用 LLM。我现在最常使用的模型是 [DeepSeek V4](https://deepseek.com)，以[opencode](https://opencode.ai/) 为主要 Agent。

我坚定支持开源软件和开源文化。我倾向于使用开源工具链。
